# Font licences

The three typefaces bundled in `public/fonts/` are published under the SIL Open
Font License 1.1, which requires its text to accompany the font files.

| font | files | licence |
| --- | --- | --- |
| JetBrains Mono | `JetBrainsMono-Regular.ttf`, `jetbrains-mono-latin.woff2` | [`JetBrainsMono-OFL.txt`](./JetBrainsMono-OFL.txt) |
| DM Sans | `dm-sans-latin.woff2` | [`DMSans-OFL.txt`](./DMSans-OFL.txt) |
| Cormorant Garamond | `cormorant-garamond-latin.woff2`, `cormorant-garamond-italic.woff` | [`Cormorant-OFL.txt`](./Cormorant-OFL.txt) |

Each file is the verbatim `OFL.txt` from that font's own upstream repository,
carrying its own copyright line. They were not reconstructed — a wrong
copyright line asserts something false about someone else's work, which is
worse than a missing file.

Sources: [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono),
[googlefonts/dm-fonts](https://github.com/googlefonts/dm-fonts),
[CatharsisFonts/Cormorant](https://github.com/CatharsisFonts/Cormorant).
