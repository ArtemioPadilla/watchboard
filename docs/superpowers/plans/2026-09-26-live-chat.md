# First-party live chat (Worker + Durable Objects) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One chat room per enabled tracker, served by the existing `watchboard-push` Worker on a new host `chat.watchboard.dev` through SQLite-backed Durable Objects with hibernatable WebSockets; reading is anonymous, writing needs a GitHub session; comments carry no tier and live in a collapsed "Community · unverified · not a source" panel; moderation is built for one person and degrades to read-only when nobody is watching; cost ceiling is 0 USD (Workers Free). Everything ships **disabled** first.

**Architecture:** `worker/index.ts` dispatches on `url.hostname` before its existing path `switch`: `chat.watchboard.dev` goes to an isolated module `worker/chat/router.ts`, every other host keeps today's push/newsletter behaviour byte for byte (regression-tested). The chat router refuses everything with 503 unless the secret `CHAT_ENABLED` is exactly `"true"`, and 404s any room slug not in the `CHAT_ROOMS` var **before** calling `idFromName`. Two SQLite DO classes: `ChatRoom` (one per `tracker:{slug}`; messages, counters, room mode, local ban cache; hibernatable WebSockets, per-socket state in `serializeAttachment`, one `alarm` for retention/attended hours) and `ChatMod` (singleton `global`; bans, reports, decisions, global mode, term list, erasure fan-out). Pure logic (normalisation, filters, rate limits, session tokens, Origin checks) lives in plain modules unit-tested inside the Workers runtime. The wire protocol is a dependency-free parser in `src/lib/community/protocol.ts`, imported by both the Worker and the site island. On the site, `ChatPanel.tsx` mounts only when `PUBLIC_CHAT_ENABLED === 'true'` at build time **and** the tracker has `community.chat: true`; it opens no socket until the reader opens the panel. A pure client state machine (`chat-client.ts`) owns reconnect/backoff/ack timeouts and is unit-tested in node; Playwright covers the rendered panel.

**Tech Stack:** Cloudflare Workers + Durable Objects (SQLite backend, WebSocket Hibernation API), `wrangler@4.124.0`, `@cloudflare/vitest-pool-workers@0.22.0`, `vitest@4.1.0`, `@cloudflare/workers-types` — all in a **separate `worker/package.json`** (see Deviations D1). Site: Astro 5 static, React 19 islands, TypeScript, Vitest 4 (node env), Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-26-live-chat-design.md` (cited below as "spec §N"). Research on alternatives, moderation, DSA, minors, GDPR, CSP and the tier promise is reused from `docs/superpowers/specs/2026-09-24-live-comments-design.md` (cited as "09-24 §N"), not redone.

## Global Constraints

All values live in `worker/chat/limits.ts` (Worker) or
`src/lib/community/protocol.ts` (shared) — never re-declared elsewhere.

- **Host:** `CHAT_HOST = 'chat.watchboard.dev'`. Routes: `GET /room/{slug}` (WebSocket upgrade), `GET /health`, `GET /auth/github/start`, `GET /auth/github/callback`, `POST /auth/logout`, `GET|POST /notice`, `GET|POST /admin/*`, `POST /me/erase`, `GET /me/export`.
- **Kill switches:** secret `CHAT_ENABLED` — chat serves only when it is exactly the string `"true"`; absent/anything else → `503 {"error":"chat_disabled"}` before any DO access. Var `CHAT_ROOMS` — comma-separated slugs; initial value `"_canary"`. Build var `PUBLIC_CHAT_ENABLED` — the panel mounts only when exactly `"true"`.
- **Room ids:** `roomName(slug) = 'tracker:' + slug`; slug regex `/^(_canary|[a-z0-9][a-z0-9-]{0,63})$/`; `ChatMod` id `idFromName('global')`.
- **Origins:** var `CHAT_ALLOWED_ORIGINS`, comma-separated, production value `"https://watchboard.dev"`; `wrangler dev` / tests add `http://localhost:4321` through `.dev.vars` / the test config only. Upgrade with a missing or foreign `Origin` → 403 before the DO.
- **Sizes:** `MAX_BODY_CHARS = 500` (after normalisation), `MAX_FRAME_BYTES = 4096` (bigger → close 1009), `HISTORY_LIMIT = 100`, `ACK_TIMEOUT_MS = 10_000`.
- **Rate limits (spec §3.7):** burst 1 msg / `8_000` ms (slow mode `60_000` ms); `20` msgs / hour / identity / room; `100` msgs / UTC day / identity (see D3); `10` reports / hour / identity; room `40` msgs / minute → auto `slow` for `15` min + alert; room `1_500` accepted msgs / UTC day and `5_000` connections / UTC day → `readonly` reason `daily_budget` until 00:00 UTC; `300` concurrent sockets per room (more → 1013); `3` consecutive rejected sends → close 1008.
- **Budget:** `CHAT_MAX_ROOMS = 5` (site build test and Worker startup check); alert at `0.7` of any room budget.
- **Identity:** uid format `'gh:' + github numeric id`; handle shown `'gh/' + login`; minimum account age `CHAT_MIN_ACCOUNT_AGE_DAYS` (Worker var, **no default**, set by Task 16 from Q3); reserved handles `['watchboard','admin','mod','moderator','reuters','ap','bbc','afp','cnn','aljazeera']` compared case-insensitively on the login.
- **Session:** cookie `__Host-wb_chat` (`Secure; HttpOnly; SameSite=Lax; Path=/; Max-Age=2592000`), token `base64url(json) + '.' + base64url(HMAC-SHA256)` with secret `CHAT_SESSION_KEY`, payload `{uid, handle, iat, exp, gen}`; OAuth state cookie `__Host-wb_oauth` (`Max-Age=600`), PKCE S256, scope `read:user` only.
- **Ban keys:** `uidHmac(uid) = hex(HMAC-SHA256(CHAT_BAN_KEY, uid))`; never a public salt (09-24 §7, `:626-632`).
- **Retention (spec §3.8, confirmed by Q11 before the pilot):** visible `30` days; held `72` h; removed rows keep `body = ''`; reports and decisions `183` days; bans `≤ 365` days; no IP stored anywhere; Worker `observability` stays off.
- **Modes:** `open | slow | readonly | closed`; reasons `owner | global | daily_budget | auto_slow | filters_unavailable | attended_hours | unreviewed_report`.
- **Error codes (stable, i18n keys `chat.err.{code}`):** `rate_limited`, `too_long`, `empty`, `banned`, `auth_required`, `account_too_new`, `readonly`, `closed`, `bad_frame`, `not_author`, `report_limited`, `duplicate`, `shouting`, `unknown`.
- **Alerts:** only to secret `TELEGRAM_ALERT_CHAT_ID` via `TELEGRAM_BOT_TOKEN`; never message text, handle or uid — only room, category, count and the `/admin` URL. The string `TELEGRAM_CHANNEL_ID` must not appear under `worker/` (test).
- **Tier separation (09-24 §3, spec §5.2):** `ChatMessage` has no `tier|source|sourceTier|pole|contested|media|confidence|verified` key; nothing under `src/lib/schemas.ts`, `scripts/`, `mcp/`, `video/`, `src/pages/api/`, `src/pages/**/rss*`, `src/pages/feeds*` imports `lib/community/`; panel CSS never references `--tier-`, `--accent-red`, `--accent-amber`, `.source-chip`, `.freshness-indicator`, `SourceStatusChip` or a monospace font. Enforced by Task 9 and Task 23.
- **No tracking:** no PostHog call, no `localStorage`/`sessionStorage`/`document.cookie` in any community file (the session cookie is set by the Worker on its own host). Enforced by Task 9.
- **No silent success (`docs/silent-failure-patterns.md`):** every test asserts on the artefact — the SQLite row, the frame another socket received, the header the server sent, the HTML in `dist/`. `ack` is sent only after the SQL write returns; erasure reports the count it re-reads.
- **Type check:** root `npx astro check` OOMs locally; use `npx tsc --noEmit -p . 2>&1 | grep -E 'community|live-layers|tracker-config|MobileTab|translations'` (must print nothing) for the site and `npm --prefix worker run typecheck` for the Worker.
- **Git:** feature branch per task group (`feat/chat-foundations`, `feat/chat-backend`, `feat/chat-panel`), never `main`. Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`. Paths with `[tracker]` go through `git add --literal-pathspecs -- "src/pages/[tracker]/index.astro"` (memory: pathspec bracket trap).

## Deviations from the spec

Each is recorded again in ADR-0003 (Task 6).

- **D1 — `worker/` becomes its own npm package** instead of adding
  `wrangler` and the pool to the root `devDependencies` (spec §11.2/§12
  step 0). Reason: the root `Dockerfile` runs `npm ci` on `node:22-alpine`;
  `workerd` ships glibc binaries and its postinstall would put ~100 MB and a
  musl risk into the self-hosting image for code the image never runs. The
  Worker's tests therefore run through `npm --prefix worker test`, which
  `npm test` at the root calls (Task 1) so CI cannot skip them.
- **D2 — the protocol parser is dependency-free, not Zod** (spec §3.4 says
  Zod on both ends). Reason: `src/lib/community/protocol.ts` is compiled by
  the site (root `zod@3`) and by the Worker package (no zod). Importing
  `zod` from a file under `src/` would resolve to the root `node_modules`,
  which the Worker's deploy job does not install. Hand-written guards with
  exhaustive tests (Task 8) give the same rejection behaviour.
- **D3 — the per-identity daily cap (100) is counted per room**, not across
  rooms. Reason: a cross-room count needs a `ChatMod` call on every send
  (one extra DO request per message) for a cap that, with ≤ 5 rooms, is at
  most 5× looser. The hourly cap (20/room) still binds first. If the pilot
  shows abuse spread across rooms, this is revisited.
- **D4 — bans are pushed to rooms** (`ChatMod` fans out to the ≤ 5 rooms in
  `CHAT_ROOMS` and each room keeps a `bans` table) rather than rooms reading
  `ChatMod` per message; same reason as D3.
- **D5 — root `vitest.config.ts` does not include `worker/**`** (spec §11.1
  says it should). Worker tests need the Workers runtime (`cloudflare:test`),
  which the root node environment cannot load; they run in
  `worker/vitest.config.ts` instead and Task 2 adds a guard test that fails
  if `npm test` stops calling them.
- **D6 — no licence-plate pattern in the PII filter** (spec §4.1.5 lists
  "matrículas"). Reason: plate formats differ per country and a generic
  letters-digits pattern matches weapon designations that fill a conflict
  site ("F-16", "S-400", "M142"), holding normal messages all day. Plates
  are handled by reports (`personal_data`) and the term list instead.

```ts
export async function handleChat(request: Request, env: ChatEnv, _ctx: ExecutionContext): Promise<Response> {
  const url = new URL(request.url);
  const path = url.pathname.replace(/\/+$/, '') || '/';
  if (path === '/health' && !chatEnabled(env)) {
    return chatJson({ enabled: false, version: env.CHAT_VERSION ?? 'unknown' });
  }
  if (!chatEnabled(env)) return chatJson({ error: 'chat_disabled' }, 503);

  const m = /^\/room\/([^/]*)$/.exec(path);
  if (m) {
    let slug: string;
    try { slug = decodeURIComponent(m[1]); } catch { return chatJson({ error: 'not_found' }, 404); }
    if (!SLUG_RE.test(slug) || !parseRooms(env.CHAT_ROOMS).has(slug)) return chatJson({ error: 'not_found' }, 404);
```

```ts
import type { ChatMessage, ChatMode, ChatModeReason, ChatErrorCode, HoldCode, ReportCategory } from './types';

export const MAX_FRAME_BYTES = 4096;
export const MAX_BODY_CHARS = 500;
export const MAX_RAW_BODY_CHARS = 2000;
export const REPORT_CATEGORIES = ['illegal', 'harassment', 'personal_data', 'spam', 'misinformation', 'other'] as const satisfies readonly ReportCategory[];
const MODES = ['open', 'slow', 'readonly', 'closed'] as const;
const REASONS = ['owner', 'global', 'daily_budget', 'auto_slow', 'filters_unavailable', 'attended_hours', 'unreviewed_report'] as const;
const HOLDS = ['slur', 'pii', 'link', 'duplicate', 'reports'] as const;
const ERRORS = ['rate_limited', 'too_long', 'empty', 'banned', 'auth_required', 'account_too_new', 'readonly', 'closed', 'bad_frame', 'not_author', 'report_limited', 'duplicate', 'shouting', 'unknown'] as const;
const NONCE_RE = /^[A-Za-z0-9_-]{8,64}$/;
const LANG_RE = /^[a-z]{2}(-[A-Z]{2})?$/;

type Obj = Record<string, unknown>;
const isObj = (v: unknown): v is Obj => typeof v === 'object' && v !== null && !Array.isArray(v);
const onlyKeys = (o: Obj, allowed: readonly string[]) => Object.keys(o).every((k) => allowed.includes(k));
const isId = (v: unknown): v is number => Number.isInteger(v) && (v as number) > 0;
const isTs = (v: unknown): v is number => Number.isInteger(v) && (v as number) >= 0;
const oneOf = <T extends string>(v: unknown, list: readonly T[]): v is T => typeof v === 'string' && (list as readonly string[]).includes(v);
const optional = (o: Obj, k: string, ok: (v: unknown) => boolean) => !(k in o) || ok(o[k]);

function parseJson(raw: string): Obj | null {
  if (new TextEncoder().encode(raw).length > MAX_FRAME_BYTES) return null;
  try { const v: unknown = JSON.parse(raw); return isObj(v) ? v : null; } catch { return null; }
}

export function parseClientFrame(raw: string | ArrayBuffer): ClientFrame | null {
  if (typeof raw !== 'string') return null;
  const o = parseJson(raw);
  if (!o) return null;
  switch (o.t) {
    case 'send':
      if (!onlyKeys(o, ['t', 'body', 'nonce', 'lang'])) return null;
      if (typeof o.body !== 'string' || o.body.length > MAX_RAW_BODY_CHARS) return null;
      if (typeof o.nonce !== 'string' || !NONCE_RE.test(o.nonce)) return null;
      if (!optional(o, 'lang', (v) => typeof v === 'string' && LANG_RE.test(v))) return null;
      return o.lang === undefined ? { t: 'send', body: o.body, nonce: o.nonce } : { t: 'send', body: o.body, nonce: o.nonce, lang: o.lang as string };
    case 'report':
      if (!onlyKeys(o, ['t', 'id', 'category']) || !isId(o.id) || !oneOf(o.category, REPORT_CATEGORIES)) return null;
      return { t: 'report', id: o.id, category: o.category };
    case 'delete':
      if (!onlyKeys(o, ['t', 'id']) || !isId(o.id)) return null;
      return { t: 'delete', id: o.id };
    default:
      return null;
  }
}

function isMessage(v: unknown): v is ChatMessage {
  if (!isObj(v) || !onlyKeys(v, ['id', 'ts', 'handle', 'body', 'lang', 'state', 'mine', 'holdCode', 'reason', 'moderator'])) return false;
  return isId(v.id) && isTs(v.ts) && typeof v.handle === 'string' && typeof v.body === 'string'
    && oneOf(v.state, ['visible', 'held', 'removed'] as const)
    && optional(v, 'lang', (x) => typeof x === 'string' && LANG_RE.test(x))
    && optional(v, 'mine', (x) => typeof x === 'boolean')
    && optional(v, 'moderator', (x) => typeof x === 'boolean')
    && optional(v, 'holdCode', (x) => oneOf(x, HOLDS))
    && optional(v, 'reason', (x) => typeof x === 'string');
}

export function parseServerFrame(raw: string): ServerFrame | null {
  let o: Obj;
  try { const v: unknown = JSON.parse(raw); if (!isObj(v)) return null; o = v; } catch { return null; }
  const modeOk = () => oneOf(o.mode, MODES) && optional(o, 'reason', (x) => oneOf(x, REASONS)) && optional(o, 'until', isTs);
  switch (o.t) {
    case 'hello': {
      if (!onlyKeys(o, ['t', 'mode', 'reason', 'until', 'history', 'me']) || !modeOk()) return null;
      if (!Array.isArray(o.history) || !o.history.every(isMessage)) return null;
      if (!optional(o, 'me', (m) => isObj(m) && onlyKeys(m, ['handle', 'canWrite', 'cooldownMs'])
        && typeof m.handle === 'string' && typeof m.canWrite === 'boolean' && isTs(m.cooldownMs))) return null;
      return o as ServerFrame;
    }
    case 'ack':
      return onlyKeys(o, ['t', 'nonce', 'id', 'state', 'holdCode']) && typeof o.nonce === 'string' && isId(o.id)
        && oneOf(o.state, ['visible', 'held'] as const) && optional(o, 'holdCode', (x) => oneOf(x, HOLDS)) ? (o as ServerFrame) : null;
    case 'msg':
      return onlyKeys(o, ['t', 'm']) && isMessage(o.m) ? (o as ServerFrame) : null;
    case 'remove':
      return onlyKeys(o, ['t', 'id', 'reason']) && isId(o.id) && optional(o, 'reason', (x) => typeof x === 'string') ? (o as ServerFrame) : null;
    case 'mode':
      return onlyKeys(o, ['t', 'mode', 'reason', 'until']) && modeOk() ? (o as ServerFrame) : null;
    case 'err':
      return onlyKeys(o, ['t', 'code', 'nonce', 'cooldownMs']) && oneOf(o.code, ERRORS)
        && optional(o, 'nonce', (x) => typeof x === 'string') && optional(o, 'cooldownMs', isTs) ? (o as ServerFrame) : null;
    default:
      return null;
  }
}

export const encode = (frame: ServerFrame | ClientFrame): string => JSON.stringify(frame);
```

```ts
const INVISIBLE = /[\u0000-\u0008\u000B-\u001F\u007F-\u009F​-‏‪-‮⁠-⁩﻿]/g;
export function normalize(raw: string): string {
  let s = raw.normalize('NFKC').replace(INVISIBLE, '');
  s = s.replace(/(\P{M})(\p{M}{3,})/gu, (_m, base: string, marks: string) => base + [...marks].slice(0, 2).join(''));

}
```

```ts
export class FiltersUnavailable extends Error {}
export function termsUsable(t: TermList | null): t is TermList {
  return !!t && Number.isInteger(t.version) && t.version >= 1
    && Object.values(t.terms ?? {}).reduce((n, list) => n + (Array.isArray(list) ? list.length : 0), 0) > 0;
}
export function luhn(digits: string): boolean {
  let sum = 0;
  for (let i = 0; i < digits.length; i++) {
    let d = Number(digits[digits.length - 1 - i]);
    if (i % 2 === 1) { d *= 2; if (d > 9) d -= 9; }
    sum += d;
  }
  return digits.length >= 13 && sum % 10 === 0;
}
const EMAIL = /[^\s@]+@[^\s@]+\.[a-z]{2,}/i;
const PHONE = /(?:\+?\d[\s().-]{0,2}){9,15}/;
const CARD = /\b(?:\d[ -]?){13,19}\b/g;
const IBAN = /\b[A-Z]{2}\d{2}(?:\s?[A-Z0-9]{4}){2,7}(?:\s?[A-Z0-9]{1,4})?\b/;
const COORDS = /-?\d{1,3}\.\d{4,}\s*,\s*-?\d{1,3}\.\d{4,}/;
const ADDRESS = [
  /\b\d{1,5}[a-z]?\s+(?:[\p{L}'-]+\s+){1,3}(?:street|st|avenue|ave|road|rd|lane|ln|boulevard|blvd|drive|dr)\b/iu,
  /\b(?:calle|avenida|av\.?|rua|travessa|paseo|carrera)\s+(?:[\p{L}.'-]+\s+){1,4}\d{1,5}\b/iu,
  /\b\d{1,5}(?:\s?(?:bis|ter))?,?\s+(?:rue|avenue|boulevard|bd|allée|chemin|place)\b/iu,
];
export function containsPii(body: string): boolean {
  if (EMAIL.test(body) || PHONE.test(body) || IBAN.test(body) || COORDS.test(body)) return true;
  for (const m of body.matchAll(CARD)) if (luhn(m[0].replace(/\D/g, ''))) return true;
  return ADDRESS.some((re) => re.test(body));
}
const LINK = [/\bhttps?:\/\//i, /\bwww\./i, /\b[a-z0-9-]{2,}\.(?:com|org|net|io|ru|info|xyz|me|ly|gg|co|tk|to|su|cn|link|click|top)\b/i];
export const containsLink = (body: string): boolean => LINK.some((re) => re.test(body));

function hasSlur(body: string, t: TermList): boolean {
  const words = new Set(fold(body).split(' ').filter(Boolean));
  const flat = squash(body);
  for (const list of Object.values(t.terms)) {
    for (const raw of list) {
      const term = squash(raw);
      if (!term) continue;
      if (term.length >= 5 ? flat.includes(term) : words.has(term)) return true;
    }
  }
  return false;
}
function isShouting(body: string): boolean {
  if (/(.)\1{9,}/u.test(body)) return true;
  const letters = body.match(/\p{L}/gu) ?? [];
  const upper = letters.filter((c) => c !== c.toLowerCase()).length;
  return letters.length >= 20 && upper / letters.length > 0.7;
}
export function evaluate(i: FilterInput): Verdict {
  if (!termsUsable(i.terms)) throw new FiltersUnavailable('term list missing, empty or unversioned');
  if (i.body.length === 0) return { kind: 'reject', code: 'empty' };
  if (i.ownRecent.includes(i.body)) return { kind: 'reject', code: 'duplicate' };
  if (i.othersSameBody >= 2) return { kind: 'hold', code: 'duplicate' };
  if (hasSlur(i.body, i.terms)) return { kind: 'hold', code: 'slur' };
  if (containsPii(i.body)) return { kind: 'hold', code: 'pii' };
  if (containsLink(i.body) && i.acceptedCount < 3) return { kind: 'hold', code: 'link' };
  if (isShouting(i.body)) return { kind: 'reject', code: 'shouting' };
  return { kind: 'accept' };
}
```

```ts
import type { ChatMode } from '../../src/lib/community/types';
import { LIMITS } from './limits';

export const utcDay = (now: number) => new Date(now).toISOString().slice(0, 10);
export const utcHour = (now: number) => new Date(now).toISOString().slice(0, 13);
export const msUntilUtcMidnight = (now: number) => 86_400_000 - (now % 86_400_000);
const msUntilNextHour = (now: number) => 3_600_000 - (now % 3_600_000);

export function checkIdentity(u: IdentityUsage, now: number, mode: ChatMode): RateDecision {
  if (mode === 'readonly' || mode === 'closed') return { ok: false, cooldownMs: 0 };
  if (u.dayCount >= LIMITS.perDay) return { ok: false, cooldownMs: msUntilUtcMidnight(now) };
  if (u.hourCount >= LIMITS.perHour) return { ok: false, cooldownMs: msUntilNextHour(now) };
  const gap = mode === 'slow' ? LIMITS.slowBurstMs : LIMITS.burstMs;
  const wait = u.lastSendAt + gap - now;
  return wait > 0 ? { ok: false, cooldownMs: wait } : { ok: true };
}
export const checkReport = (reportsThisHour: number) => reportsThisHour < LIMITS.reportsPerHour;
export function roomMinute(prev: { start: number; count: number }, now: number) {
  if (now - prev.start >= 60_000) return { start: now, count: 1, triggerSlow: false };
  const count = prev.count + 1;
  return { start: prev.start, count, triggerSlow: count === LIMITS.roomPerMinute };
}
export function roomBudget(msgs: number, conns: number) {
  const ratio = Math.max(msgs / LIMITS.roomMsgsPerDay, conns / LIMITS.roomConnsPerDay);
  return { ratio, alert: ratio >= LIMITS.budgetAlertRatio, exhausted: ratio >= 1 };
}
```

```ts
const enc = new TextEncoder();
export function b64url(bytes: ArrayBuffer | Uint8Array): string {
  const u = bytes instanceof Uint8Array ? bytes : new Uint8Array(bytes);
  let s = '';
  for (const b of u) s += String.fromCharCode(b);
  return btoa(s).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}
export function fromB64url(s: string): Uint8Array {
  if (!/^[A-Za-z0-9_-]*$/.test(s)) throw new Error('bad base64url');
  const bin = atob(s.replace(/-/g, '+').replace(/_/g, '/') + '='.repeat((4 - (s.length % 4)) % 4));
  return Uint8Array.from(bin, (c) => c.charCodeAt(0));
}
const key = (secret: string) => crypto.subtle.importKey('raw', enc.encode(secret), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign', 'verify']);
export async function sign(secret: string, data: string) { return b64url(await crypto.subtle.sign('HMAC', await key(secret), enc.encode(data))); }
export async function verifySig(secret: string, data: string, sig: string) {
  try { return await crypto.subtle.verify('HMAC', await key(secret), fromB64url(sig), enc.encode(data)); } catch { return false; }
}
export async function hmacHex(secret: string, data: string) {
  const mac = new Uint8Array(await crypto.subtle.sign('HMAC', await key(secret), enc.encode(data)));
  return [...mac].map((b) => b.toString(16).padStart(2, '0')).join('');
}
```

```ts
export async function signSession(p: SessionPayload, key: string) {
  const body = b64url(new TextEncoder().encode(JSON.stringify(p)));
  return `${body}.${await sign(key, body)}`;
}
export async function verifySession(token: string, key: string, now: number): Promise<SessionPayload | null> {
  const parts = token.split('.');
  if (parts.length !== 2 || !(await verifySig(key, parts[0], parts[1]))) return null;
  try {
    const p = JSON.parse(new TextDecoder().decode(fromB64url(parts[0]))) as SessionPayload;
    if (typeof p.uid !== 'string' || typeof p.handle !== 'string' || !Number.isInteger(p.gen) || typeof p.exp !== 'number') return null;
    return p.exp * 1000 > now ? p : null;
  } catch { return null; }
}
export function readCookie(req: Request, name: string): string | null {
  for (const part of (req.headers.get('Cookie') ?? '').split(';')) {
    const i = part.indexOf('=');
    if (i > 0 && part.slice(0, i).trim() === name) return part.slice(i + 1).trim();
  }
  return null;
}
export const sessionCookie = (token: string) => `${SESSION_COOKIE}=${token}; Path=/; Secure; HttpOnly; SameSite=Lax; Max-Age=${SESSION_TTL_S}`;
```
